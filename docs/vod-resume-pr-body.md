The existing VOD resume prompt deleted progress when declined and identified every item by its playback URL. This change adds a keyboard-first **View > Continue Watching** library and stable, account-scoped Xtream movie/episode identities. URL/token/extension changes no longer invalidate newly stored Xtream progress when the provider content ID remains the same.

The library lists title, saved position, local last-watched time and availability, with selected-item checking, Resume/Enter, Delete and confirmed Clear All. It resolves current URLs through current sources on a worker without opening a media stream. Removed/ambiguous content and failed network checks are separate outcomes; progress is retained. Episode resolution fetches only its own series. Plain M3U keeps conservative exact-URL/source matching and never guesses by title.

Playback consent is explicitly **Resume / Play from Beginning / Cancel**. Cancel/Escape leave the current player and subtitle session intact. Accepted state is staged until play; outgoing session-stop checkpoints cannot recreate intentionally removed progress. Exact legacy Xtream records migrate without losing the newer saved position; unknown legacy URLs/unscoped M3U records are preserved instead of reassigned arbitrarily. Deleting an active saved entry suppresses its checkpoints until the next launch without stopping playback.

Custom dialogs use the shared modal notification guard. Late replies after close/destruction are rejected, playlist-generation changes block stale launches, and modal checkpoint updates are merged from current config. Bookmark metadata is bounded/whitelisted, excludes stream URLs and credentials, and remains part of encrypted settings export. Sources are checked independently of the main playlist filter; restore remains built-in-player-only, with no new external-player or casting seek claims.

New strings are translated in all 13 application locales with rebuilt MO files; earlier translations are retained. Hungarian VOD help and all 23 new Hungarian strings received final contextual/language review before packaging. Existing help anchors and generic locale-audit gates are unchanged.

Validation: **2559 passed, 162 skipped, 5 deselected** in the broad local Linux run; **119 passed, 1 skipped** in the affected model/UI-wiring/VOD/modal/localization/Debian set. Ruff, whitespace checks, 772-source-message coverage across all translated catalogues and compiled gettext round-trips passed. Native Windows/frozen/JAWS/NVDA/real-provider acceptance is still required. Exact host exclusions, migration boundaries and native acceptance cases are documented in `docs/vod-resume-validation.md` and `docs/vod-resume-library.md`. No CI exclusions or release/audit gates are relaxed.
